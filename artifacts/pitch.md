Наш проект — корпоративная система адаптации новых сотрудников. 
Решает задачу онбординга: от выдачи индивидуального плана до сбора 
обратной связи и аналитики. 
В системе четыре роли: новый сотрудник, наставник, HR BP-специалист и администратор.

Основные возможности:

Интерактивный план адаптации (для новых сотрудников). Пошаговый маршрут на испытательный 
срок с разбивкой по этапам. Задачи сортируются по срочности: 
просроченные, на сегодня, предстоящие, выполненные. Прогресс-бар показывает процент 
прохождения, отдельно выделены контрольные встречи с руководителем. При отсутствии плана — заглушка.

Отметка выполнения задач. Сотрудник самостоятельно фиксирует завершение задачи 
чекбоксом. Прогресс пересчитывается и отображается наставнику. Предусмотрена возможность 
отмены ошибочной отметки. В перспективе — запрос подтверждения от наставника для критических задач.

Справочник контактов «Кто есть кто». Древовидная структура отделов и команд. Карточки 
сотрудников с ролью, тегами ответственности, контактами (email, мессенджеры, телефон). 
Быстрый поиск и кнопка «Задать вопрос» для создания черновика письма.

Регулярный сбор обратной связи. Еженедельные короткие опросы 
(шкала настроения, понятность задач, текстовое пожелание). 
После отправки опрос на неделю деактивируется.

Дашборд наставника. Список подопечных с ключевыми метриками: дата выхода, процент выполнения 
плана, статус последнего опроса. Клик по сотруднику открывает просмотр его плана.

Возможность настройки плана подопечных наставником. Изменение дедлайнов задач, 
добавление уникальных задач в любой этап, удаление только вручную добавленных. 
Системные задачи скрываются, но не удаляются.

Конструктор шаблонов планов (Администратор). Создание библиотеки сценариев адаптации 
под разные должности. Шаблон состоит из этапов, каждый — из набора задач с типом 
(доступ, обучение, встреча) и автоматическим расчетом сроков от даты выхода.

Управление пользователями. Администратор заводит сотрудника, назначает роль, 
наставника и шаблон плана. Сотрудник получает доступ. 
В перспективе — управление группами/отделами.

Аналитика и статистика. Два разреза: прогресс выполнения планов 
(по статусам, департаментам) и график настроения по результатам опросов. 
Фильтрация по группам и наставникам.

Аутентификация через JWT (MVP). Ручное создание учётных записей администратором. 
Вход по email и паролю.
В будущем — интеграция с корпоративным SSO, принудительная 
смена пароля при первом входе, блокировка уволенных.

Почему сделано именно так:

Единый источник информации по плану адаптации исключает неопределённость для нового сотрудника.

Автоматическое отслеживание дедлайнов и прогресса снимает нагрузку с наставника и HR.

Разделение ролей даёт каждому участнику только нужный функционал.

Конструктор шаблонов позволяет масштабировать онбординг без ручного повторения.

JWT-аутентификация в MVP позволяет быстро запустить систему без сложной интеграции 
с корпоративной инфраструктурой, сохраняя возможность будущего перехода на SSO.

Система покрывает полный цикл адаптации: от назначения плана до 
сбора обратной связи и аналитики эффективности онбординга.
